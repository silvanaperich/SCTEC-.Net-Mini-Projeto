## CONTEXTUALIZAÇÃO ##

No setor automotivo (concessionárias, locadoras de veículos e seguradoras), a **vistoria técnica** é um processo indispensável. Antes de comprar um carro usado para revenda ou aceitá-lo como entrada na troca por um zero-quilômetro, a empresa precisa verifi car rigorosamente se o veículo cumpre os requisitos mínimos de segurança e conservação mecânica.  
Neste mini-projeto, você (ou sua squad) assumirá o papel de Desenvolvedor(a) Back-End .NET Júnior contratado(a) por uma rede de concessionárias. Sua missão é construir uma engine (motor de processamento) via Console Application em C# que receba a inspeção técnica de um veículo, aplique as regras do Checklist de Vistoria, calcule a pontuação final de aproveitamento, classifi que a situação do veículo e emita um relatório detalhado com os serviços recomendados para a ofi cina.
Este projeto visa consolidar os conteúdos de C# e POO estudados:
- Lógica de programação e tipos primitivos (string, int, double, bool);
- Manipulação de coleções (List<T>);
- Estruturas de controle (if/else, switch, foreach, for);
- Programação Orientada a Objetos: Classes, Atributos, Propriedades, Construtores, Encapsulamento, Uso do this, Herança (:), sobreescrita (virtual/override) e Polimorfi smo;
- Versionamento com Git/GitHub
